# NextCue GitHub Pages site

This directory contains the static public website used by NextCue's App Store listing. It provides the product overview, privacy policy, and support information in Japanese and English.

## Publishing

- Repository: https://github.com/Dorakochiaaa/nextcue-site
- Public site: https://dorakochiaaa.github.io/nextcue-site/
- Privacy policy: https://dorakochiaaa.github.io/nextcue-site/privacy.html
- Support: https://dorakochiaaa.github.io/nextcue-site/support.html
- Contact: https://github.com/Dorakochiaaa/nextcue-site/issues/new

Publish the contents of this directory at the root of the repository's GitHub Pages source. No build step is required.

## Local pages

- [`index.html`](index.html) links to both the privacy and support pages.
- [`privacy.html`](privacy.html) contains the bilingual privacy policy.
- [`support.html`](support.html) contains bilingual usage help and the GitHub Issues contact link.
